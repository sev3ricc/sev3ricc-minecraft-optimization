# sev3ricc-minecraft-optimization
Advanced client-side performance optimizer for Minecraft 1.21.11 (Fabric). Boosts FPS, optimizes rendering, and includes a custom settings HUD.Продвинутый клиентский оптимизатор для Minecraft 1.21.11 (Fabric). Повышает FPS, оптимизирует рендеринг и включает кастомный HUD настроек.


Real Performance Booster (Sev3ricc Edition)

Мощный клиентский оптимизатор для Minecraft 1.21.11 (Fabric), созданный для выжимания максимального FPS из любого железа.

Обычные моды просто отключают графику, делая игру некрасивой. Real Performance Booster работает иначе — он внедряется в архитектуру движка (через Mixin) и заставляет его работать эффективнее, не уродуя картинку.
⚙️ Как именно работает оптимизация?

Наш мод использует комплексный подход к перераспределению ресурсов процессора (CPU) и видеокарты (GPU). В основе лежат асинхронные вычисления и умное кэширование.

1. Перехват и разгрузка рендер-потока
Мод перехватывает цикл отрисовки (runTick) и отсекает лишние вызовы, которые не влияют на визуальную картинку. Это снижает оверхед на Java-машине и предотвращает микро-фризы.

2. Умное кэширование данных (Smart Chunk Caching)
Когда вы поворачиваете камеру, игра заново просчитывает видимость блоков. Наш мод запоминает уже просчитанные сектора чанков в оперативной памяти и берет готовые данные, минуя этап повторной сборки полигонов (Mesh Building).

3. Асинхронное отсечение сущностей (Async Entity Culling)
Мод проверяет положение мобов и предметов в пространстве в отдельном потоке. Если сущность не попадает в поле зрения (Frustum) или перекрыта блоками (Occlusion), её отрисовка полностью отключается еще до того, как GPU начнет её обрабатывать.

4. Оптимизация сборщика мусора (Garbage Collector Tuning)
Java (на которой работает Майнкрафт) периодически вызывает сборщик мусора, что вызывает подтормаживания. Мод перераспределяет выделение памяти для легких объектов (частицы, текстуры интерфейса), снижая частоту вызовов GC и делая игру плавнее в долгих сессиях.

5. Батчинг (Batching) освещения и физики
Мод объединяет расчеты освещения от факелов и лавы, а также обновления поршней. Вместо того чтобы считать каждый источник отдельно, мод отправляет один пакет данных (Draw Call) на видеокарту. Это сильно экономит ресурсы CPU в пещерах и на редстоун-фермах.

6. Динамический LOD (Level of Detail)
Для далеких чанков мод включает упрощенную отрисовку. Чем дальше объект, тем меньше полигонов он использует, что экономит видеопамять (VRAM) и повышает общий FPS.
🚀 Расширенное меню настроек (Booster Settings)

В главном меню игры доступна кнопка "Booster Settings" с 20 функциями тонкой настройки. Каждая галочка — это отдельный микропатч:

    Smart Chunk Caching — Кэширует уже отрисованные чанки, чтобы они не перестраивались при повороте камеры.

    Async Entity Culling — Не дает игре отрисовывать сущности и блоки, которые вы сейчас не видите.

    Dynamic Lighting Batching — Объединяет расчеты освещения в один проход, снижая нагрузку на процессор.

    Memory Leak Patcher — Исправляет внутренние утечки памяти, из-за которых падает FPS при долгой игре.

    Multithreaded Block Rendering — Распределяет отрисовку блоков на несколько ядер процессора.

    Particle Optimization — Снижает количество рассчитываемых частиц на экране (взрывы, эффекты).

    LOD Scaling — Динамически снижает детализацию далеких объектов для экономии ресурсов.

    Fast Math Library — Заменяет стандартную математику Java на ускоренные аппаратные аналоги.

    Occlusion Culling — Скрывает геометрию, которая находится за другими блоками.

    Texture Atlas Compression — Сжимает неиспользуемое пространство текстур для экономии VRAM.

    Zero-Copy Buffer Allocation — Оптимизирует передачу памяти между CPU и GPU, предотвращая задержки.

    Predictive Tick Scheduling — Планирует тики игры более эффективно для стабильной работы логики.

    Frustum Culling Enhancements — Улучшает отсечение объектов за пределами обзора камеры.

    Garbage Collector Tuning — Оптимизирует сборщик мусора Java для устранения микро-фризов.

    Smooth Lighting Caching — Кэширует данные плавного освещения для блоков, которые не менялись.

    Render Distance LOD — Снижает количество полигонов для далеких чанков.

    Entity AI Pathfinding Cache — Кэширует узлы поиска пути мобов для ускорения расчетов ИИ.

    Fluid Dynamics Optimization — Оптимизирует расчеты течения воды и лавы.

    Piston Physics Batching — Объединяет обновления поршней в пакеты, чтобы избежать лагов.

    Cloud Render Optimization — Оптимизирует отрисовку облаков.

🛠️ Установка

    Скачайте .jar файл мода.

    Поместите его в папку .minecraft/mods.

    Убедитесь, что у вас установлены Fabric API, Cloth Config и Mod Menu.

    Запустите игру и наслаждайтесь стабильным FPS!
